# Word Hunt — EF-101-P01\n\nA Hangman game using HTML/CSS/vanilla JavaScript, FastAPI, and Neon PostgreSQL.\n\n## Deploy setup\n1. In Vercel, set the project root to the repository root and add `DATABASE_URL` as an environment variable for Preview and Production.\n2. Ensure the Neon database user can create tables. The API initializes `words` and `game_sessions` tables when used.\n3. Deploy, then test `/api/health`, `/api/new-game?difficulty=easy`, guessing, score saving, and the leaderboard.\n\n## Interface\n- Progressive SVG hangman drawing, one part per incorrect guess.\n- Difficulty-specific hints, keyboard and on-screen letter input, and toast notifications.\n- Collapsible top-50 leaderboard, system-default light/dark colors, and switchable modern/typewriter styling.\n\n## Rules\n- Easy 3–5 letters, Medium 6–8, Hard 9+ letters.\n- Eight incorrect guesses. Repeated guesses do not cost a chance.\n- Score: remaining chances × 10 + bonus (Easy 0, Medium 20, Hard 40).\n- The starter word set is intentionally small; add the full course word bank to Neon for the required word counts.\n\nNever commit real database credentials. `DATABASE_URL` belongs in Vercel Environment Variables, not frontend code.\n
